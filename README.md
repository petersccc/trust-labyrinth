# Trust Labyrinth

Lead magnet for Peters Cross-Cultural Communication: 7 rooms about trust
problems at Chinese companies in Germany, in German (default), English
and Chinese. Built from `trust-labyrinth-spec.md`, with the approved
mockups as the visual reference.

Run locally: `pwsh -File serve.ps1`, then open http://localhost:8745
(`.claude/launch.json` entry `trust-labyrinth`).

## Files

- `index.html`: page shell, link preview tags, Cloudflare Web Analytics
  beacon (token still `YOUR_BEACON_TOKEN`, replace once the site exists
  in Cloudflare Web Analytics).
- `content.js`: generated from `trust-labyrinth-content.json`, word for
  word. Regenerate rather than edit when the copy changes.
- `content-extra.js`: the spec templates (room label, page title and
  description), Katarina's added texts (company name error, map exit
  word), and the German and Chinese equivalents of `bold_words_en`.
- `app.js`: rooms, routing (section 5), insight cards, buttons and
  countdown (section 6), result logic (section 7), language switch and
  address bar (section 10), the form.
- `clickup-submit.js`: posts the submission and `ref` to the Worker.
  `CLICKUP_WORKER_URL` is empty until the Worker is deployed.
- `worker/`: the Trust Labyrinth's own Cloudflare Worker (see its README).
- `functions/_middleware.js`: Cloudflare Pages Function that gives link
  previews the right title, description and image for `?lang=en` and
  `?lang=zh` (preview crawlers do not run JavaScript).
- `privacy-notice.html`: generated from the three privacy notice
  Markdown files, `?lang=` picks the language.
- `img/`, `og/`: cropped photos and 1200×630 preview images, generated by
  `tools/make-images.ps1` from the original photos.

## Behaviour notes

- Room order: 1, 4, 5, 2, 3, 6, 7 when only card 1 (and possibly card 4)
  is picked in Room 1, otherwise 1 to 7.
- Stuck room: most problem cards, ties go to the lower room number. The
  map rings every room with at least one problem card.
- Nothing is sent before the form is submitted. If ClickUp cannot be
  reached, the visitor still sees the thank you slide (as in the
  checkups) and the error is logged in the browser console.
